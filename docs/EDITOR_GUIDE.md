# Profile editing guide for CANN members

You do **not** need Git or a command line for routine profile edits.

## Change your bio or links in the browser

1. Sign in to GitHub.
2. Open the CANN website repository.
3. Go to `site/people/your-name.html`.
4. Click the pencil icon (**Edit this file**).
5. Change your profile text or links.
6. Scroll to **Commit changes**.
7. Select **Create a new branch for this commit and start a pull request**.
8. Give the pull request a short title, e.g. `Update Ash profile`.
9. Submit it.

The website maintainer reviews the change. Once merged, the website deploys automatically.

## Change your photo

Because photos are binary files, ask the website maintainer to upload the new image, or use the **Profile update request** issue template.

## Why a pull request?

It keeps the live site protected while still allowing every lab member to propose their own updates. It also leaves a history of what changed and allows a change to be reversed.

## When you leave CANN

Your public profile/alumni information may remain on the website, but your editing access should be removed from the CANN website GitHub teams during offboarding.
